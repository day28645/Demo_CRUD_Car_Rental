🚗 Car Rental System - Web Application

ระบบเช่ารถยนต์ออนไลน์ของร้าน Car’s Day พัฒนาด้วย ASP.NET Web Forms (C#) เพื่ออำนวยความสะดวกให้ลูกค้าสามารถจองรถยนต์ได้อย่างง่ายดาย ผ่านการเลือก สถานที่ วัน และเวลา ตามต้องการ

ผู้ใช้งานสามารถสมัครสมาชิก เข้าสู่ระบบ และทำรายการจองรถยนต์ได้ด้วยตนเอง รวมถึงสามารถยกเลิกการจอง โดยมี

👤 ขอบเขตของลูกค้า (Customer)
สมัครสมาชิก (Register)
เข้าสู่ระบบ (Login)
สร้างรายการจองรถยนต์ (Booking)
เลือกสถานที่รับ - ส่งรถ
เลือกวันและเวลาในการใช้งาน
ยกเลิกการจอง (มีค่าธรรมเนียม)
